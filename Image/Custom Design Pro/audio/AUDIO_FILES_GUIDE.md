## 🎛️ مشخصات فنی / Technical Specifications

### فرمت فایل / File Format:
- **اولویت اول:** MP3 (320kbps یا 192kbps)
- **فرمت جایگزین:** OGG (برای پشتیبانی بهتر مرورگر)

### کیفیت صدا / Audio Quality:
- **موسیقی:** 192kbps یا بالاتر
- **افکت‌ها:** 128kbps (کافی است)
- **Sample Rate:** 44.1kHz یا 48kHz

### حجم فایل / File Size:
- **هر ترک موسیقی:** حداکثر 5MB
- **هر افکت صوتی:** حداکثر 200KB

## 🎮 نحوه استفاده / How to Use

بعد از قرار دادن فایل‌ها:

1. **Settings** را باز کنید (دکمه چرخ دنده)
2. بخش **Background Music** را پیدا کنید
3. دکمه **On** را بزنید → موسیقی شروع می‌شود
4. از منوی **Select Track** ترک دلخواه را انتخاب کنید
5. با **Volume Slider** صدا را تنظیم کنید
6. برای **Sound Effects** هم دکمه On/Off را امتحان کنید

## ❓ سوالات متداول / FAQ

### Q1: آیا باید حتماً MP3 باشد؟
**A:** بله، MP3 بهترین پشتیبانی را در همه مرورگرها دارد. اگر فقط OGG پیدا کردید، می‌توانید با ابزارهای آنلاین مثل https://convertio.co به MP3 تبدیل کنید.

### Q2: آیا می‌توانم نام فایل‌ها را عوض کنم؟
**A:** خیر! نام فایل‌ها باید دقیقاً مطابق راهنما باشد (track1.mp3, click.mp3و غیره).

### Q3: اگر موسیقی پخش نشد چه کنم؟
**A:** 
1. مسیر فایل را چک کنید (audio/music/track1.mp3)
2. Console مرورگر را باز کنید (F12) و خطاها را ببینید
3. فرمت فایل را بررسی کنید (باید MP3 باشد)

### Q4: چند تا ترک الزامی است؟
**A:** حداقل track1.mp3 را قرار دهید تا سیستم کار کند. بقیه اختیاری هستند.

## 🎨 نکات حرفه‌ای / Professional Tips

1. **Loop Points:** آهنگ‌هایی انتخاب کنید که به راحتی loop می‌شوند (بدون سکته صدا)
2. **Volume Balance:** موسیقی نباید خیلی بلند باشد، حجم پیشنهادی: 50%
3. **Consistency:** همه آهنگ‌ها باید حجم صدای نسبتاً یکسانی داشته باشند
4. **Testing:** هر فایل را قبل از قرار دادن در برنامه امتحان کنید
